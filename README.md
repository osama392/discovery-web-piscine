## 🐧 Project 00: Linux + Git + GitHub

> **Shell commands · Remotes · SSH**

Setting up a professional developer workflow from the command line.

**What I learned**
- Navigating the filesystem with core shell commands (`ls`, `cd`, `pwd`, `mkdir`, `touch`, `cp`, `mv`, `rm`, `cat`)
- File permissions and basic process management
- Initializing repositories and tracking changes with Git (`init`, `add`, `commit`, `status`, `log`, `diff`)
- Branching and merging (`branch`, `checkout` / `switch`, `merge`)
- Working with remotes (`remote add`, `push`, `pull`, `clone`, `fetch`)
- Generating SSH keys and authenticating securely with GitHub

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
git remote add origin git@github.com:<username>/<repo>.git
git push -u origin main
```

## 🧱 Project 01: HTML Fundamentals

> **Structure · Semantics · Tables · Forms**

Building well-structured, accessible web pages with pure HTML.

**What I learned**
- Document structure: `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`, meta tags
- Semantic elements: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
- Text content, lists, links, images and media
- Data tables with `<thead>`, `<tbody>`, `<th>`, `colspan` / `rowspan`
- Forms and inputs: text, email, password, radio, checkbox, select, textarea, validation attributes
- Accessibility basics: `alt` text, `<label>` associations, heading hierarchy
